# Plano de produção — Episódio 1

## Etapa concluída no repositório
- Roteiro cronometrado de 60 segundos.
- Guia visual e regras de continuidade.
- Prompts de geração para as sete cenas.
- Legendas SRT iniciais.
- Script de exportação vertical com opção de queima de legendas.
- Validador Python e workflow do GitHub Actions para verificar os materiais.

## Próximas etapas de produção audiovisual
1. Criar model sheets aprovados para Moranguinha, mãe, Abacaxi e figura misteriosa.
2. Construir e riggar os quatro personagens em Blender.
3. Criar os cenários reutilizáveis e bloquear câmeras.
4. Gerar animação de cada plano, com expressões e lip-sync.
5. Gravar ou sintetizar as vozes em português brasileiro e montar a trilha/SFX.
6. Editar, revisar legendas e renderizar o MP4 vertical.

## Critério de pronto
O episódio só será considerado finalizado quando o MP4 1080×1920, 30 fps, com áudio e legendas, tiver sido renderizado e assistido para controle de qualidade. Os arquivos atuais são materiais de pré-produção e automação; ainda não são o vídeo final.

## Limitação operacional
Este repositório não inclui render farm ou serviço de geração de vídeo em nuvem. A renderização 3D depende de Blender e hardware local ou de um serviço externo escolhido e autorizado pelo proprietário.
